Enterprise Core Internal API Gatewayv1.4.2

Служебный программный интерфейс единого шлюза авторизации, синхронизации данных и управления распределенными микросервисами компании. Доступ к конечным точкам API (Endpoints) разрешен исключительно для авторизованных узлов внутренней инфраструктуры облака при наличии валидного заголовка X-API-KEY.

Base URL

Production Cluster Gateway/api/v1

Authentication

SchemeApiKeyAuth
TypeapiKey
Locationheader
NameX-API-KEY

Уникальный токен доступа к микросервисам инфраструктуры.

Авторизация узла (Синхронизация)

Проверка подлинности сервиса и генерация сессионного JWT-токена для внутреннего обмена данными.

post/api/v1/auth/login

Responses

  • 200Успешная авторизация, токен выпущен.
  • 401Ошибка безопасности. Неверный X-API-KEY.

Обновление сессии

Продление времени жизни текущего токена авторизации.

post/api/v1/auth/refresh

Responses

  • 200Токен успешно обновлен.

Получить список активных сессий

Запрос реестра активных авторизованных пользователей из распределенной базы данных.

get/api/v1/users/sync

Responses

  • 200Реестр успешно выгружен.
  • 401Доступ запрещен.

Проверка статуса узла по ID

get/api/v1/users/{id}

Responses

  • 200Узел активен и стабилен.

Обновление конфигурации узла

put/api/v1/users/{id}

Responses

  • 200Конфигурация успешно применена.

Принудительное отключение узла

delete/api/v1/users/{id}

Responses

  • 204Узел удален из реестра балансировщика.

Сбор телеметрии

Потоковый запрос для сбора системных логов, утилизации CPU/RAM и сетевой активности контейнеров.

get/api/v1/metrics/stream

Responses

  • 200Поток метрик инициализирован.

Проверка жизнеспособности (Liveness Probe)

Стандартный эндпоинт для автоматических систем мониторинга облака (K8s / Yandex Cloud) для проверки статуса контейнера.

get/api/v1/healthz

Responses

  • 200Контейнер работает стабильно.
